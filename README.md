# Portfolio

Source of [chaithanyavemuri.xyz](https://chaithanyavemuri.xyz/), a static site hosted on Netlify.

No build step: the repository root is the publish directory (`netlify.toml`). Pages are plain HTML under their route folders, and styles, scripts, fonts and images live in `assets/`.

To preview locally:

```
python3 -m http.server 8000
```
